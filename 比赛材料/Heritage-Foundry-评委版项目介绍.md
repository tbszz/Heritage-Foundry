# Heritage Foundry｜遗产铸造局

> **让千年非遗，不只被看见，更能被这一代人重新创造。**

## 一句话介绍

**Heritage Foundry 是一个 AI 驱动的非遗文创与手作方案生成平台。**  
它把非遗技艺、流行 IP 与现代生活载体放进同一座“数字铸造厂”，让用户从一次灵感选择出发，完成 **文化理解、创意生成、AI 视觉设计、真实 3D 建模、AR 空间预览、手作图纸输出与作品保存** 的完整创作旅程。

这不是一座把非遗封存在玻璃展柜里的线上博物馆，而是一台让传统文化持续产生新作品、新表达与新消费场景的**文化创造引擎**。

---

## 项目宣言

非遗真正的危机，从来不只是“没人知道”，而是年轻人知道以后，仍然不知道如何靠近、如何参与、如何把它带回自己的生活。

Heritage Foundry 给出的答案是：

> **不要只让年轻人观看传统，而要把创造传统的工具交到他们手中。**

用户可以选择苗绣、剪纸、皮影、景德镇陶瓷、南京云锦、唐卡等非遗技艺，搭配喜爱的文化 IP、文创载体与视觉风格，由 AI 将抽象灵感转化为可视、可改、可旋转、可落地制作的创作方案。

从“我对非遗有一点兴趣”，到“这是我亲手参与设计的非遗作品”，Heritage Foundry 正在补上中间最关键的一公里。

# 一、为什么是 Heritage Foundry？

## 传统非遗传播的三道断层

### 1. 内容断层：看得懂历史，却记不住文化

大量非遗内容仍停留在图文介绍、静态展陈和单向讲解中。信息很完整，但年轻用户缺少参与感，文化很难转化为真正的记忆。

### 2. 创作断层：有兴趣，却没有专业设计能力

非遗纹样、色彩、工艺和寓意都有深厚门槛。普通用户即使产生灵感，也往往止步于“不会画、不会建模、不会打样”。

### 3. 落地断层：生成了一张图，却没有变成作品

许多 AI 创意工具止步于“好看的一张图”。但文创真正的价值在于继续走向三维展示、实体制作、材料准备、文化叙事和作品沉淀。

## 我们的解法

Heritage Foundry 把原本割裂的环节连接成一条可连续体验的数字生产线：

**认识非遗 → 组合灵感 → AI 生成 → 视觉编辑 → 3D 转换 → AR 预览 → 图纸与物料 → 故事表达 → 作品保存**

它让文化不再只是被检索的信息，而是成为一种能够被调用、被组合、被制作的“创作能力”。

# 二、核心体验：一座人人都能使用的数字非遗工坊

## 1. 非遗灵感库：把文化知识变成可创作的语言

平台目前沉淀了 **18 类非遗与传统工艺内容**，覆盖传统美术、刺绣、印染、陶瓷、织锦、雕刻、戏剧及传统技艺等多个门类，包括：

- 布老虎、剪纸、皮影、苗绣、扎染
- 景德镇陶瓷、中国书法、中国篆刻、南京云锦
- 泥塑、制茶技艺、风筝、花灯
- 木雕、石刻、木版年画、唐卡、玉雕

每项技艺不只是一个名称，而包含文化故事、视觉色彩、典型纹理、模型资产和适配 AI 的提示语言。  
例如，苗绣可以被拆解为“密集针脚、银饰反光、蝴蝶妈妈纹、几何彩线”；南京云锦则被转译为“金线织锦、团花纹、皇家织造光泽、层叠纹样”。

**文化在这里不是标签，而是一套能够进入生成过程的设计基因。**

## 2. 创意生成工作台：把灵感选择变成完整方案

用户可以组合：

- 一项非遗技艺
- 一个喜爱的 IP 或角色方向
- 一种文创载体
- 一套视觉风格

平台随后生成针对性的创意方案与视觉结果。用户不需要掌握专业设计软件，也能完成过去需要插画师、产品设计师与文化顾问共同参与的早期创意工作。

它降低的不是文化价值，而是文化创作的门槛。

## 3. AI 图像生成与编辑：让创意可以被看见、被修改

项目接入 Google Gemini 图像能力，可完成方案图生成与基于原图的二次编辑。

与通用生图不同，Heritage Foundry 的生成过程由非遗知识、工艺语言、载体属性和视觉风格共同约束，使结果尽可能从“泛国风图片”走向“具有具体工艺辨识度的文创方案”。

## 4. 从 2D 灵感到真实 3D：让作品真正“立起来”

项目设计了统一的 image-to-3D 任务系统：

- 在线环境可接入 **Meshy**，生成带 GLB 输出的真实 3D 模型；
- 本地环境可运行 **TripoSR sidecar**，完成离线三维重建；
- 前端不需要关心底层供应商差异，只处理统一的排队、生成、成功、失败状态；
- 输出模型可继续进入 Three.js 展示与 AR 体验。

这意味着一张 AI 文创概念图，不再只是展示终点，而可以成为三维数字资产的起点。

## 5. 3D 与 AR：把非遗作品放进真实生活

平台使用 Three.js 提供 3D 载体预览，并通过 `<model-viewer>` 支持 WebXR / Scene Viewer。

用户可以：

- 在桌面端对作品进行 360° 环绕观察；
- 在兼容的安卓或鸿蒙浏览器中，以真实尺度将文物或文创模型放进房间；
- 在生产之前感受作品的尺寸、体量与空间效果。

**从屏幕里的传统，到房间里的文化，距离只剩一次点击。**

## 6. 从“好看”走向“能做”：手作图纸与材料清单

Heritage Foundry 不满足于生成效果图。平台还能进一步输出：

- 可制作的像素化拼豆图纸
- 颜色与数量统计
- 材料清单
- 非遗故事卡

这让 AI 结果可以从数字内容继续走向课堂活动、亲子手作、文创打样、社团实践和研学课程。

## 7. 作品保存与公共画廊：让一次生成成为文化资产

平台通过 Supabase 保存作品，并支持读取最近公开创作。用户的灵感、方案、图纸、故事与视觉结果可以被持续沉淀，而不是在生成结束后消失。

当越来越多用户参与创作，Heritage Foundry 将不只是一件工具，也有潜力成长为一个由公众共同建设的**数字非遗创意社区**。

# 三、最值得评委记住的五个亮点

## 亮点 01：不是“展示非遗”，而是“生产新非遗表达”

项目从单向传播跃迁到共同创作。用户不再是旁观者，而是参与设计、选择、修改和制作的创作者。

## 亮点 02：不是一次 AI 生图，而是一条完整创作链

很多产品结束于图片，Heritage Foundry 则继续走向 3D、AR、图纸、物料、故事和作品保存。  
**它交付的不是一张图，而是一套可以继续制作和传播的文创方案。**

## 亮点 03：传统文化与年轻审美之间，有了一座实时翻译器

平台把复杂的工艺特征转译为 AI 可理解、用户可选择的设计语言，再将流行 IP 和现代载体引入创作过程。传统不必迎合潮流，而是获得一种与当代对话的新语法。

## 亮点 04：线上效率与本地自主性兼顾

3D 能力同时支持云端 Meshy 与本地 TripoSR。统一任务协议隔离底层差异，既便于快速上线，也为本地部署、数据控制和教学环境保留空间。

## 亮点 05：真正考虑了“能不能上线、能不能跑”

项目具备生产化思维：

- 前后端分离，提供清晰 API；
- AI、3D 与数据服务均有明确的未配置降级；
- 生成接口具有限流与错误分类；
- 密钥与服务地址保留在服务端；
- 3D 文件经过格式与几何有效性校验；
- 支持 Vercel、单进程与 Docker 部署；
- GitHub Actions 自动执行测试与构建；
- 大型 3D 模型与字体通过资产管线显著压缩。

尤其是资产优化方面，仓库给出的处理目标为：

- 3D 模型经 Draco + WebP 管线由约 **420 MB 压缩至 14 MB**
- 字体经子集化由约 **71 MB 压缩至 1.8 MB**

这说明团队不仅在做“能演示的概念”，也在认真解决真实 Web 产品的加载与交付问题。

# 五、应用场景：它可以走进哪里？

## 1. 非遗研学与美育课堂

学生不再只抄写知识点，而是完成一次“选技艺—做设计—讲故事—制成品”的项目式学习。教师可以围绕同一非遗主题组织作品共创与成果展。

## 2. 博物馆与非遗馆互动体验

观众扫描入口即可把馆藏元素转化为个性化文创方案，再通过 3D 与 AR 预览。参观由“看完即走”变成“带着自己的创作离开”。

## 3. 文创品牌的低成本灵感验证

品牌可以快速探索非遗技艺与不同 IP、载体和风格的组合，在进入设计深化与实体打样前，更快形成候选方向。

## 4. 非遗传承人与设计师的数字助手

平台可以帮助传承人整理视觉语言、扩展传播形式，也能帮助年轻设计师在尊重工艺特征的前提下寻找当代表达。

## 5. 文旅景区与城市文化名片

平台可按地域配置本地非遗库，形成“一地一馆、一技一故事、一人一作品”的互动体验，为城市文化传播、游客纪念品与社交分享提供新入口。

# 六、商业与社会价值

## 社会价值：让非遗从“被保护”走向“可持续参与”

保护非遗的终极目标不是让它保持静止，而是让它仍然有人理解、有人使用、有人愿意继续创造。Heritage Foundry 用年轻人熟悉的 AI、3D 和 AR 交互，降低第一次接触与第一次创作的门槛。

## 教育价值：把文化知识变成项目式学习成果

平台天然适合课程化：每一次生成都可以对应文化研究、视觉设计、数字技术、手工实践与口头表达等多维能力。

## 产业价值：压缩文创早期创意链路

它可以把分散的文化检索、灵感草图、效果预览和基础物料整理集中到一个工作台中，为后续专业设计与打样提供更明确的起点。

## 平台价值：沉淀可复用的文化设计基础设施

随着非遗技艺、载体模板、地区内容与作品数据持续增加，平台有机会形成面向学校、场馆、文旅机构和文创品牌的模块化能力：

- 面向公众的免费创作入口
- 面向学校的课程与班级作品空间
- 面向场馆的定制互动展项
- 面向品牌的创意工作台与 API 服务
- 面向地区的非遗数字资产与文创共创平台
