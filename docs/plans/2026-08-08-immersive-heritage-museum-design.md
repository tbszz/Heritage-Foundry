# 沉浸式非遗博物馆设计方案

## 设计读法

这是面向比赛评委、年轻公众和非遗爱好者的数字博物馆重构。设计语言是“铜织天宫 · 夜游百工馆”：当代铜织立面负责宏伟尺度，绢、木、漆、石和真实 3D 馆藏负责传统文化质感。

参考图提供的是构图语法，而不是配色模板：

- 单一完整世界，不做卡片拼盘；
- 建筑是绝对主角；
- 巨型文字制造尺度；
- 悬浮导航像展馆铭牌；
- 建筑、文字、角色形成前后遮挡；
- 首屏只有“推门入馆”一个主要动作。

## 方案比较

### A. 铜织天宫（采用）

使用现有 `option-a-copper-weave-palace.png` 作为首页外景，现代博物馆体量与传统编织肌理并存。点击入馆后进入已有丝绢、木构和 3D 长廊。

优点：宏伟、独特、符合参考图的建筑中心构图，也避免传统宫殿模板感。

### B. 绢幕大馆

直接以 `museum-cinematic.webp` 内厅作为首页。艺术性强，但缺少“推门进入一座馆”的仪式。

### C. 夜游宫苑

使用红墙金瓦和宫灯外景。识别度高，但容易接近古风游戏与普通文旅页面。

## 首页构图

```text
[印章 品牌]   云上展厅 百工典藏 山河图志 AI造物 共创画廊   [推门入馆]

             遗                         见
   [皮影人物]          [铜织博物馆主体]          [布老虎]
                 一馆藏百艺，一念续千年
                   [推门入馆]  今日首展
```

巨型“遗见”位于建筑后方。建筑位于中间景深层，皮影与布老虎是前景活态馆藏。首屏馆藏统计降为底部细线信息，不使用通用玻璃数据卡。

## 交互叙事

1. 外景首帧立即可见，铜织立面和巨字缓慢显现。
2. 皮影在左侧幕后轻移，点击进入“纸上万象”。
3. 布老虎在右侧石阶轻踏，点击进入“经纬成章”。
4. 点击“推门入馆”，外景用 1.2–1.6 秒沉稳溶解，按需初始化 3D 长廊。
5. 长廊中滚轮或方向键沿固定轨道移步，指针控制有限回望，点击门进入四章展厅。
6. 点击展品进入独立 3D 鉴赏弹窗；可旋转、缩放，关闭后回到原展位。

角色不是灵宠，不聊天、不跟随用户；它们是被唤醒的馆藏迎宾者。ChatCut/Seedance 当前不可调用，且首版无需视频即可完成真实点击反馈与连续视角转换。

## 页面语言

- 云上展厅：外景 → 推门 → 长廊 → 四章展厅。
- 百工典藏：按真实技艺和材料浏览。
- 山河图志：深色绢本地图，古铜省界，朱砂当前区域。
- AI 造物：改称“造物案台”，左工艺签、中作品台、右工序谱。
- 共创画廊：策展墙与博物馆展签，点赞是朱砂落印。

## 造物案台

左栏使用渐进式工艺签选择技艺、题材、载体和气质；中央作品台始终占最大面积，图像与 3D 同台；右栏展示“取纹样 → 定载体 → 炼成像 → 生立体 → 入画廊”的工序谱、真实 3D 状态和作品故事。拼豆图纸与材料清单在下方展开。

默认题材改为瑞兽、戏曲人物、山海传说、敦煌飞天、江南花鸟等原创中国文化主题；旧 ID 保留兼容，但不再作为默认 UI 选项。

## 动效

- 品牌曲线：`cubic-bezier(.22, 1, .36, 1)`
- 反馈：120–160ms
- 卡片/面板：380–480ms
- 页面：700–950ms
- 推门：1.2–1.6s
- 不使用线性空间运动和弹跳 overshoot
- 同时运动元素不超过可见元素的 1/3
- reduced motion 下使用 300ms 溶解

## 12 轮视觉验收

1. 一级导航和灵宠清理。
2. 1440×900 首页建筑中心构图。
3. 色彩与三层字体收束。
4. 皮影与布虎迎宾交互。
5. 推门入馆连续转场。
6. 长廊与四章展厅输入不冲突。
7. 3D 藏品旋转、缩放与返回。
8. 造物案台三栏信息层级。
9. 山河图志直达与视觉连接。
10. 共创策展墙与朱砂落印。
11. 390×844、键盘、焦点与 reduced motion。
12. 去模板化、性能、测试与构建终审。

## 验证

- Vitest 合约与行为测试采用 RED → GREEN。
- 内置浏览器固定记录 1440×900 与 390×844。
- 每轮记录截图或验收 JSON 于 `.omx/artifacts/visual-ralph/immersive-museum/`。
- 最终运行 `npm test`、`npm run build` 与 `git diff --check`。
