# 新馆模型风格基准

用户要求新增模型与现有馆藏统一，并尽可能美观。2026-09-07 在同一个 ArtifactStage 灯光环境实际查看了现有 `porcelain-vase.glb`、`teapot.glb`、`embroidered-tiger.glb`；以这些 GLB 的视觉效果为基准，而非重新定义整馆风格。

## 共同特征

- 真实传统器形，适合近距离观看的精致手工展品感。
- 青花瓷保留清晰、繁而有序的深蓝纹样和温润白釉；紫砂保留细颗粒陶土；布艺保留织物、缝线和刺绣质感。
- 色彩依工艺取材，布老虎可用浓郁传统彩色，不能为了统一而把所有品类改成同一种颜色。
- 轮廓完整、比例协调、细节清楚；保留民间造型特征，避免无依据的卡通夸张和自动生成的融化细节。
- 反光克制且符合材料。陶土、织物不呈塑料亮面；瓷器保留柔和釉光；金属另按真实材质处理。

## 生成与审核

100 件清单的共同提示已加入上述约束；具体器形描述仍优先。复杂器形使用经检查的图像参考，参考图注明生成来源或真实出处，不将生成图称为馆藏照片。

每件在同一展台看整体、侧面和关键细节；同时核对形制、纹样清晰度、材质和与原模型的协调程度。技术通过或缩略图好看均不直接等于入馆通过。已有新模型仍需按新增风格要求复核。

保持一件模型常驻、2 万三角面/8 MiB 技术上限。不能靠增加面数或堆积附件追求细节，也不能为了压缩抹掉辨识度。贴图和几何压缩保留原文件，以便回退。

## 当前证据边界

已完成三个原馆藏 GLB 的浏览器风格对照。风格标准已落实到后续任务提示；不是对尚未生成的 100 件模型的完成声明。实际验收数量以审核账本及馆藏 manifest 为准。
